# Leontiy Bondarchuk — Portfolio

Персональне портфоліо у стилі dark minimalism / neon cyberpunk. Сайт двомовний (UA/EN), адаптивний і готовий для GitHub Pages.

## Запуск локально
Відкрий `index.html` у браузері.

## Публікація на GitHub Pages
1. Створи публічний репозиторій, наприклад `portfolio`.
2. Завантаж усі файли та папку `assets` у корінь репозиторію.
3. Відкрий **Settings → Pages**.
4. У **Build and deployment** вибери **Deploy from a branch**.
5. Вибери `main` та `/ (root)`, натисни **Save**.
6. Сайт з'явиться за адресою `https://z3roch.github.io/portfolio/`.
